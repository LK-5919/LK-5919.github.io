# SCSS 实现主题颜色切换

## 定义主题颜色配置

`myStyle.scss` 文件：

```scss
/*
定义一个map，类似js中的object
*/
$themes: (
    light: (
        bgColor: #fff,
        textColor: #000
    ),
    dark: (
        bgColor: #000,
        textColor: #fff
    )
);
```

## 定义工具函数

`handler.scss` 文件：

```scss
@import './myStyle.scss';

@mixin useTheme {
    // 循环map，生成html属性选择器在各个主题下的定义的样式，这里的$key 对应 $themes 中的 light, $value 对应 light 定义的对象
    @each $key, $value in $themes {
        // 将当前循环的主题类型提升为全局变量，以便于getVar函数使用
        $curTheme: $key !global;
        // 这里的 & 符号相当于占位符，会被解析成当前调用此mixin的类名
        html[data-theme='#{$key}'] & {
            // 类似插槽， 会将调用useTheme时，自定义的属性传入替换
            @content;
        }
    }
}

// 定义函数获取指定主题下指定变量的值
@function getVar($paramName){
    // 先获取到当前循环的主题对象，$curTheme 为@each循环时提升的全局对象
    $themeMap: map-get($themes, $curTheme);
    // 根据传入的key，获取指定主题下的变量值，然后返回
    @return map-get($themeMap, $paramName);
}

// 定义一个获取当前主题下背景颜色的函数
@mixin getThemeBackgroundColor($key) {
    @include useTheme {
        background-color: getVar($key);
    }
}
```

## 使用

`index.scss` 文件

```scss
@import './handler.scss'
.item {
    // 设置背景颜色
    @include getThemeBackgroundColor('bgColor');
}
```

`APP.vue` 文件

```html
<script setup>
// 获取主题
const theme = ref(localStorage.getItem('theme') || 'light');
nextTick(()=>{
    // 设置主题
  window.document.documentElement.setAttribute("data-theme", theme.value);
});
</script>
```
