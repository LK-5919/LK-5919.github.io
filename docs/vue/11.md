# Vue 知识归纳

## 常见修饰符

1. 表单元素的修饰符：

   - `.number`：应用于表单输入元素时，确保用户输入的是数字类型。
   - `.trim`：在 input 元素上，提交表单时自动去除首尾空白字符。
   - `.lazy`：应用于 `v-model` 时，会转变为“change”事件而不是“input”事件，意味着只有在失去焦点或按回车键时才会触发数据同步。
2. v-model 的修饰符：

   - `.model`：Vue 2.x 中，`.sync` 修饰符可以实现父子组件之间 props 的双向绑定；在 Vue 3.x 中，改为了 `.model` 修饰符来实现同样的效果。
3. 组件 Props 的修饰符：

   - `.prop`：在 Vue 3 中，如果需要将一个变量作为 prop 传递给子组件，并保持响应式，可以使用 `.prop` 修饰符。
4. 其他常见修饰符：

   - 这些修饰符主要用于事件绑定（`v-on` 或 `@`），而不是数据绑定。例如：
     - `.stop`：阻止事件冒泡。
     - `.prevent`：阻止事件的默认行为。
     - `.once`：事件只会触发一次。
     - `.capture`：事件在捕获阶段触发。
     - `.self`：仅当事件在元素自身（而非子元素）触发时才触发回调。
     - `.native`：监听组件根元素上的原生事件。

### sync 修饰符

在 Vue.js 中，`.sync` 修饰符主要用于父子组件间的双向绑定。在 Vue 2.x 中，如果你想让一个子组件能够更新父组件传递过来的 props，并且父组件也能实时响应这些变化，这时就可以使用 `.sync` 修饰符。

Vue 2.x 中的使用示例：

```html
<!-- 父组件 -->
<template>
  <child-component :my-prop.sync="parentValue"></child-component>
</template>

<script>
import ChildComponent from './ChildComponent.vue';

export default {
  components: { ChildComponent },
  data() {
    return {
      parentValue: '初始值',
    };
  },
};
</script>
```

```html
Html
<!-- 子组件 -->
<template
  <div>
    <button @click="updateValue"更新值</button>
  </div>
</template
<script>
export default {
   props: {
    myProp: String,
  },
  methods: {
    updateValue() {
      this.$emit('update:my-prop', '新值');
    },
  },
};
</script>
```

在上述例子中，`.sync` 修饰符实际上做了如下工作：

1. 将 `:my-prop.sync="parentValue"` 转换为：

   - `:my-prop="parentValue"`：父组件将 `parentValue` 作为 props 传递给子组件。
2. 子组件通过 `$emit('update:my-prop', newValue)` 触发一个自定义事件，通知父组件更新 `parentValue`。

Vue 3.x 的变化： 在 Vue 3.x 中，`.sync` 修饰符已经被弃用，取而代之的是 `.model` 修饰符，或者直接使用 v-model 在子组件上配合 `modelValue` 和 `update:modelValue` 来实现类似的功能。

```html
<!-- Vue 3.x 子组件定义 -->
<script setup>
defineProps({
  msg: String,
});
defineEmits(['update:msg']);
const updateValue = () => {
  emit('update:msg', '新值');
};
</script>

<!-- Vue 3.x 父组件使用 -->
<template>
  <child-component v-model:msg="msg"></child-component>
</template>
```

## vue2 与 vue3 中 v-model 的区别

Vue 2.x 和 Vue 3.x 中 `v-model` 的实现确实存在一些重要的区别，主要包括以下几个方面：

1. 默认 Prop 和事件名：

   - Vue 2.x 中，`v-model` 默认绑定到子组件的 `value` 属性，并期望子组件通过 `$emit('input', newValue)` 触发更新。
   - Vue 3.x 中，`v-model` 默认绑定到子组件的 `modelValue` 属性，并期望子组件通过 `$emit('update:modelValue', newValue)` 触发更新。
2. 自定义 Prop 和事件：

   - Vue 2.x 中，可以通过在子组件上设置 `model` 选项来自定义 `v-model` 绑定的 prop 名称和触发的事件名称。
   - Vue 3.x 中，可以直接在 `v-model` 后面指定自定义的 prop 名称，例如 `v-model:myProp`，并且会自动关联 `update:myProp` 事件。
3. 多 v-model 使用：

   - Vue 2.x 中，一个自定义组件内不允许同时使用多个 `v-model`。
   - Vue 3.x 改进了这一点，允许在一个自定义组件上使用多个 `v-model`，每个 `v-model` 都可以绑定到不同的 prop，并各自触发对应的事件更新。
4. `.sync` 修饰符：

   - Vue 2.x 中，`.sync` 修饰符用于实现父子组件间 props 的双向绑定，可以放在任何 prop 名称之后。
   - Vue 3.x 中，`.sync` 修饰符已经被移除，其功能被整合到了 `v-model` 中，通过自定义 prop 名称和事件触发器的形式实现类似的双向绑定。
5. Composition API 支持：

   - Vue 3 引入了 Composition API，这让自定义组件中 `v-model` 的实现更加灵活。通过 `defineProps` 和 `defineEmits` 可以更好地描述组件 Props 和自定义事件，使 `v-model` 的实现更为直观和规范。

   ### 实现一个 vue2 的 v-model

```html
<!-- MyInput 组件代码 -->
<template>
  <div>
    <input type="text" :value="value" @input="$emit('input',$event.target.value)">
  </div>
</template>

<script>
export default {
  props: {
    value: String,  // 默认接收一个名为 value 的 prop
  }
}
</script>

<!-- 父组件中使用 -->

<my-input v-model="msg"></my-input>

<!-- 其实等同于 -->

<my-input :value="msg" @input="msg = $event">
```

在 vue2 中，还提供了 model 选项，用于将属性或事件名称改为其他名称，比如上面的 MyInput 组件，我们改一下：

```html
<template>
  <div>
    <input
      type="text"
      :value="title"
      @input="$emit('change', $event.target.value)"
    />
  </div>
</template>
 
<script>
export default {
  model: {
    prop: "title", // 将默认的 prop 名 value 改为 title
    event: "change", // 将默认的事件名 input 改为 change
  },
  props: {
    title: String, // 注意 template 代码中也要修改为 title
  },
};
</script>

<!-- 父组件中使用 -->
<my-input v-model="msg"></my-input>
<!-- 其实等同于 -->
<my-input :title="msg" @change="msg = $event"></my-input>
```

### 实现一个 vue3 的 v-model

Vue3 中 v-model 带来的变化，主要变化有以下几处：

修改默认 prop 名和事件名，当用在自定义组件上时，v-model 默认绑定的 prop 名从 value 变为 modelValue，而事件名也从默认的 input 改为 update:modelValue 。在 Vue3 中编写上面那个 MyInput 组件时，就需要这样：

```html
<!-- MyInput 组件代码 Vue3 版 -->
 
<template>
  <div>
    <input
      type="text"
      :value="modelValue"
      @input="$emit('update:modelValue', $event.target.value)"  // 事件名改为 update:modelValue
    />
  </div>
</template>
 
<script>
export default {
  props: {
    modelValue: String, // 默认 prop 从 value 改为 modelValue
  },
};
</script>


<!-- 父组件中使用 -->
<my-input v-model="msg"></my-input>
<!-- 等同于 -->
<my-input :modelValue="msg" @update:modelValue="msg = $event"></my-input>
```

Vue3 中移除了 model 选项，这样就不可以在组件内修改默认 prop 名了。现在有一种更简单的方式，就是直接在 v-model 后面传递要修改的 prop 名：

```html
<template>
  <div>
    <input
      type="text"
      :value="title"
      @input="$emit('update:title', $event.target.value)"
    />
  </div>
</template>
 
<script>
export default {
  // 此时这里不需要 model 选项来修改了
  props: {
    title: String, // 修改为 title，注意 template 中也要修改
  },
};
</script>

// 要修改默认 prop 名，只需在 v-model 后面接上 :propName，例如修改为 title
<my-input v-model:title="msg"></my-input>
 
// 等同于
<my-input :title="msg" @update:title="msg = $event"></my-input>
```

此外，vue3 还支持在组件上使用多个 v-model：

```html
<!--  表单子组件 Form -->
 
<template>
  <div class="form">
    
    <label for="name">姓名</label>
    <input id="name" type="text" :value="name" @input="$emit('update:name',$event.target.value)">
    
    <label for="address">地址</label>
    <input id="address" type="text" :value="address" @input="$emit('update:address',$event.target.value)">
  
  </div>
</template>
 
<script>
export default {
  props:{
    name: String,
    address: String
  }
}
</script>
```

```html
// 父组件使用
<child-component v-model:name="name" v-model:address="address"></child-component>
    
// 将用户输入数据更新到父组件中显示
<p>{{name}}</p>
<p>{{address}}</p>
```

### 自定义 v-model 修饰符

在 Vue2 中的 v-model 上，我们用过 .trim、.lazy 和 .number 这三个内置修饰符，而 Vue3 则在这个基础上增加了自定义修饰符，即开发者可以自定义修饰符，以按需处理绑定值。

当我们在 v-model 后面加上自定义修饰符后，会通过名为 modelModifiers 的 prop 传递给子组件，子组件拿到这个修饰符名后，根据条件修改绑定值。我们来看一个例子，自定义一个修饰符 capitalize，用于将输入字符串的首字母大写。

假设自定义组件还是叫 MyInput，使用 v-model 时加上自定义修饰符 capitalize：

```html
<my-input v-model.capitalize="msg"></my-input>

<!-- MyInput 组件 -->
 
<template>
  <div>
    <input type="text" :value="modelValue" @input="emitValue" />
  </div>
</template>
 
<script>
export default {
  props: {
    modelValue: String,
    modelModifiers: {  // 自定义修饰符会默认传入这个 prop 中
      type: Object,
      default: () => ({}),
    },
  },
  mounted() {
    // 当组件 v-model 后面加上了自定义修饰符，组件内部会在 modelModifiers 上获取到修饰符状态
    console.log(this.modelModifiers); // {capitalize: true}
  },
  methods: {
    emitValue(e) {
      let value = e.target.value;
      // 如果使用了自定义修饰符，即状态为 true，就处理值
      if (this.modelModifiers.capitalize) {
        value = value.charAt(0).toUpperCase() + value.slice(1);
      }
      // emit value
      this.$emit("update:modelValue", value);
    },
  },
};
</script>
```

如果是 v-model 带上了参数，同时使用了自定义修饰符，比如这样：

```html
<my-input v-model:title.capitalize="msg"></my-input>
```

那么传入组件内部的 prop 就不再是 modelModifiers 了，而是 titleModifiers。它的格式是 arg + 'Modifiers'。此时这个组件应该这样写：

```html
<!-- MyInput 组件 -->
 
<template>
  <div>
    <input type="text" :value="title" @input="emitValue" />
  </div>
</template>
 
<script>
export default {
  props: {
    title: String,  // modelValue -> title
    titleModifiers: {  // modelModifiers -> titleModifiers
      type: Object,
      default: () => ({}),
    },
  },
  mounted() {
    console.log(this.titleModifiers); // {capitalize: true}
  },
  methods: {
    emitValue(e) {
      let value = e.target.value;
 
      // 如果使用了自定义修饰符，就处理值
      if (this.titleModifiers.capitalize) {
        value = value.charAt(0).toUpperCase() + value.slice(1);
      }
      // emit value
      this.$emit("update:title", value);
    },
  },
};
</script>
```

## Vue 的生命周期

Vue.js 框架中的生命周期钩子函数允许开发者在组件的创建、更新、渲染和销毁过程中执行特定逻辑。以下是 Vue 2.x 和 Vue 3.x 各自的生命周期钩子及其作用的详细说明：

### Vue 2.x 生命周期钩子：

1. **beforeCreate**

   - 在实例初始化完成后，数据观测和事件配置之前调用。此时，`data` 和 `computed` 属性还没有初始化，`methods` 也未绑定到 `this` 上。
2. **created**

   - 实例已经完成 `data` 属性的观测和方法、指令绑定，但 DOM 还未生成，`el` 属性没有确定。这时可以在其中发起 Ajax 请求、设置初始状态或者执行其他不需要 DOM 依赖的操作。
3. **beforeMount**

   - 在挂载开始之前调用。此时模板已编译好，即将挂载到页面上，但真实 DOM 尚未生成，`$el` 属性还不可见。
4. **mounted**

   - 组件已经被挂载到 DOM 上，所有的 DOM 相关操作都可以在这里进行，如操作 DOM 元素或第三方库初始化。
5. **beforeUpdate**

   - 当数据发生变化触发视图更新之前调用。此时新的状态已经生效，但是虚拟 DOM 还未重新渲染并打补丁到真实 DOM 上。
6. **updated**

   - 数据变化导致的视图更新完成后调用。此时组件 DOM 已完成更新，可以执行依赖新视图的操作。
7. **beforeDestroy**

   - 在实例销毁之前调用。在这一步，实例仍然完全可用，可以用来清理资源、解除绑定的事件监听器等。
8. **destroyed**

   - 实例已经被销毁，所有绑定关系都已经解绑，所有的子实例也都已被销毁。此时组件 DOM 已从 DOM 树中移除，不再可用。
9. **errorCaptured**

   - （非标准生命周期，属于全局错误处理）捕获后代组件的错误。

### Vue 3.x 生命周期钩子（Composition API 形式）：

Vue 3.x 引入了 Composition API，并优化了生命周期钩子：

1. **setup()**

   - 新增的唯一必须的方法，用于替代 `beforeCreate` 和 `created` 的部分功能，是组件实例化时最早执行的钩子，在这里可以初始化 state、响应式数据及执行副作用操作。由于是在 Vue3 的反应系统建立之初调用，这里的变量定义具有较高的优先级，且不能直接访问 `this`，而是通过 `getCurrentInstance()` 获取组件实例的上下文。
2. **onBeforeMount**

   - 替代 Vue 2.x 的 `beforeMount`，在挂载开始前执行。
3. **onMounted**

   - 同 Vue 2.x 的 `mounted`，在组件成功挂载到 DOM 后执行。
4. **onBeforeUpdate**

   - 替代 Vue 2.x 的 `beforeUpdate`，在虚拟 DOM 重新渲染之前，当组件数据变化触发更新时调用。
5. **onUpdated**

   - 同 Vue 2.x 的 `updated`，在组件更新完毕，视图已经渲染到 DOM 后执行。
6. **onBeforeUnmount**

   - 替代 Vue 2.x 的 `beforeDestroy`，在组件卸载之前调用。
7. **onUnmounted**

   - 同 Vue 2.x 的 `destroyed`，在组件完全卸载并清理资源后执行。
8. **onErrorCaptured**

   - 同 Vue 2.x，用于捕获组件内部抛出的错误。
9. **onRenderTracked / onRenderTriggered**

   - 这两个是 Vue 3 新增的用于调试的钩子，分别在依赖项跟踪时和因依赖变更触发渲染时调用，有助于观察和诊断响应式依赖问题。
10. **onActivated / onDeactivated**

   - 对于 keep-alive 组件包裹的组件，在激活/失活时会触发这两个钩子。

总结来说，Vue 3.x 的生命周期钩子更侧重于通过 Composition API 提供更细粒度的控制和更好的逻辑组织，同时也简化了生命周期流程。

## 嵌套组件的生命周期执行顺序

在 Vue 2.x 中，嵌套组件的生命周期执行顺序遵循以下基本规则：

`beforeCreate -> created -> beforeMount -> mounted -> beforeUpdate -> updated -> beforeDestroy -> destroyed`

具体来说：

- 先执行父组件的 `beforeCreate`、`created`、`beforeMount`。
- 接着执行子组件的所有 `beforeCreate`、`created`、`beforeMount`。
- 再执行子组件的 `mounted`。
- 最后执行父组件的 `mounted`。
- 更新阶段也是类似的顺序，首先父组件的 `beforeUpdate`，然后子组件的 `beforeUpdate`，接着子组件的 `updated`，最后父组件的 `updated`。

1. **渲染过程**：
   - 父组件的模板渲染过程中，会先渲染子组件，因此子组件的 DOM 挂载必然发生在父组件的 DOM 完全挂载之前。
   - 当父组件挂载完成时，这意味着它包含的所有子组件都已经挂载完成。

在 Vue 3.x 中，虽然整体生命周期的概念得以保留，但是生命周期钩子的名字和部分机制发生了变化：

1. **Vue 3.x 生命周期钩子**：
   `setup()` -> `onBeforeMount` -> `onMounted` -> `onBeforeUpdate` -> `onUpdated` -> `onBeforeUnmount` -> `onUnmounted`

Vue 3.x 中，生命周期钩子的执行仍然是由外向内的顺序，只是钩子的命名有所不同，而且 Vue 3.x 强调使用 Composition API（如 `setup` 函数），不再有 `beforeCreate` 和 `created` 这样的钩子。

总结起来，在 Vue 2.x 和 Vue 3.x 中，无论是创建还是更新阶段，父组件的生命周期钩子通常会在子组件之前开始执行，但在子组件的 DOM 挂载完成后，父组件的 `mounted`（Vue 2.x）或 `onMounted`（Vue 3.x）才会执行。

## vue 首屏优化

Vue 应用程序的首屏优化主要涉及减少加载时间和提升用户体验，以下是一系列针对 Vue 项目的首屏优化策略：

1. **服务端渲染 (SSR)**：

   - 通过 Vue Server Renderer (Vue SSR) 实现服务端渲染，让服务器生成完整的 HTML 页面，从而避免客户端 JavaScript 执行前的白屏问题，搜索引擎爬虫也能更好地抓取和索引页面内容。
2. **代码分割与懒加载**：

   - 路由懒加载：利用 Vue Router 的动态导入功能，只有当用户导航到特定路由时才加载对应的组件。
   - 异步组件：非首屏展示的组件采用异步方式加载，例如 `import()` 动态导入。
3. **构建优化**：

   - 分析并压缩代码：使用 Webpack Bundle Analyzer 等工具分析包的大小，移除未使用的代码，缩小 JS 和 CSS 文件。
   - Tree Shaking：确保生产环境开启 Tree Shaking，去除无用代码。
   - Gzip 压缩：在服务器和 Webpack 配置中启用 Gzip 压缩，减少静态资源在网络中的传输体积。
4. **CDN 加速**：

   - 将静态资源（如 JS、CSS、图片、字体等）部署到 CDN 上，以便用户从最近的 CDN 节点获取资源，降低网络延迟。
5. **静态资源优化**：

   - 图片优化：使用合适格式（WebP 等）、压缩图片大小、使用响应式图片。
   - 预加载与预连接：对首屏关键资源使用 `<link rel="preload">` 提前加载。
6. **缓存策略**：

   - 利用 HTTP 缓存头设置合理的缓存策略，让浏览器缓存静态资源，加快二次访问速度。
7. **减小 vendor 库体积**：

   - 仔细审视依赖列表，删除不必要的第三方库或者寻找更轻量级的替代品。
   - 使用像 webpack DLL Plugin 或者 Vue CLI 的 splitChunks 插件优化 chunk-vendor.js 等公共库的打包。
8. **优化 DOM 结构与 CSS**：

   - 减少不必要的 DOM 元素和样式计算，提高渲染效率。
   - 使用内联关键 CSS 以确保首屏渲染时必要的样式可用。
9. **合理组织首屏内容**：

   - 优先加载首屏可见区域的核心内容和样式，延迟加载次要内容。
10. **Vue 配置调整**：

   - 在 `vue.config.js` 中进行适当配置，如外部化大体积库到 CDN，避免在初次加载时包含在 bundle 中。

以上这些方法结合使用可以显著提升 Vue 应用程序的首屏加载性能。实际优化过程中需要根据项目具体情况进行选择和调整。

## 路由懒加载

在 Vue3 中，路由懒加载（也称为按需加载或延迟加载）是一种优化技术，它允许在用户导航到特定路由时才去加载对应的组件代码，而不是在应用程序初始化时一次性加载所有路由相关的组件。这样做的好处主要有：

1. 减少初始加载时间：仅加载首屏必需的组件，加快首次页面加载速度，提升用户体验。
2. 减小主包体积：将各个路由组件分割成多个较小的代码块，避免由于整体打包导致的 JavaScript 包过大问题。

**使用场景**：

- 对于大型单页应用，其中包含许多不同的路由和组件，但用户不一定首次访问就会浏览所有页面。
- 当希望快速呈现首屏内容，尤其是移动端网络环境不稳定时，减小初始下载的数据量尤为重要。

**如何在 Vue3 中使用路由懒加载**：

Vue3 中通常使用 ES6 动态导入语法结合 `vue-router` 来实现路由懒加载。在路由配置文件（如 `router.js` 或 `router.ts`）中，你可以这样编写异步加载的路由组件：

```javascript
import { createRouter, createWebHashHistory } from 'vue-router';

const routes = [
  {
    path: '/',
    component: () => import('@/views/Home.vue'), // 懒加载Home组件
  },
  {
    path: '/about',
    component: () => import('@/views/About.vue'), // 懒加载About组件
  },
  // 其他路由...
];

const router = createRouter({
  history: createWebHashHistory(),
  routes,
});

export default router;
```

在这个例子中，`() => import('@/views/Home.vue')` 是一个返回 Promise 的工厂函数，当 Vue Router 需要渲染对应的路由组件时，它会动态地导入指定路径的模块。这样，只有当用户导航到 `/` 或 `/about` 路由时，相应的组件代码才会被下载和执行。
