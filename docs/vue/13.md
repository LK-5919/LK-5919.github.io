# Vue3 - 实现虚拟列表组件

## 组件搭建

1. 内部容器底部添加一个空白盒子撑起父容器，产生滚动条，且空白盒子的高度，随着父容器滚动的距离进行变化；
2. 虚拟列表容器通过父容器滚动时，改变 `top` 值；
3. 监听外部父容器的滚动事件，去修改需要展示数组的起始位置；

```html
<template>
  <div ref="containerRef" @scroll="handleScroll" class="wrapper">
    <div class="inner" :style="{ top: listTop + 'px' }">
      <div v-for="item in visibleItems" :key="item.index" :style="{ height: itemHeight }">
        <slot :item="item.data" :index="item.index" />
      </div>
      <div class="bar" :style="{ height: `${(data.length - endIndex) * itemHeight}px` }"></div>
    </div>
  </div>
</template>
<script setup>
import { computed, ref } from 'vue';
const Props = defineProps({
  itemHeight: {
    type: Number,
    required: true
  },
  data: {
    type: Array,
    default: () => []
  },
})
const containerRef = ref(null);
const startIndex = ref(0);
const endIndex = ref(0);
const handleScroll = rafThrottle(() => {
  updateVisibleRange();
})
const visibleItems = computed(() => {
  if (!containerRef.value) {
    return [];
  }
  const itemCount = Props.data.length;
  const visibleItemCount = Math.floor(containerRef.value.clientHeight / Props.itemHeight) + 1;
  const safeStartIndex = Math.max(0, Math.min(startIndex.value, itemCount - visibleItemCount));
  endIndex.value = safeStartIndex + visibleItemCount;
  return Props.data.slice(safeStartIndex, safeStartIndex + visibleItemCount).map((item, index) => ({
    index: safeStartIndex + index,
    data: item
  }));
});
const listTop = computed(() => {
  return startIndex.value * Props.itemHeight;
});
function updateVisibleRange() {
  if (!containerRef.value) return;
  const scrollTop = containerRef.value.scrollTop;
  const clientHeight = containerRef.value.clientHeight;
  const itemCount = Props.data.length;
  const itemHeight = Props.itemHeight;
  const maxPossibleStartIndex = Math.max(0, itemCount - Math.ceil(clientHeight / itemHeight));
  startIndex.value = Math.min(Math.floor(scrollTop / itemHeight), maxPossibleStartIndex);
}
function rafThrottle(fn) {
  let lock = false;
  return function (...args) {
    if (lock) return;
    lock = true;
    window.requestAnimationFrame(() => {
      fn.apply(args);
      lock = false;
    });
  };
}
</script>
<style scoped lang="less">
.wrapper {
  overflow-y: scroll;
  position: relative;

  .inner {
    position: absolute;
    top: 0;
  }
}
</style>
```
